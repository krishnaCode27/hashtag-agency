HASHTAG homepage redesign
1. Open D:\Hashtag\hashtag-agency\src\App.jsx and replace all content with App.jsx from this package.
2. Open D:\Hashtag\hashtag-agency\src\App.css and replace all content with App.css from this package.
3. Keep src/main.jsx unchanged.
4. The App.jsx uses framer-motion and lucide-react, already installed in your project.
5. Run: npm run dev
6. Then verify production build: npm run build

Note: Portfolio panels are visual concepts, and the contact form opens WhatsApp. This is not yet connected to a database/admin dashboard.
